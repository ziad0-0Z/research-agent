# Cloud LLM APIs vs Self-Hosting Open-Source Models for a 5-Person Startup

## Executive summary
A 5-person startup should use cloud LLM APIs rather than self-hosting open-source models. For organizations processing low-to-moderate token volumes, hosted APIs offer a significantly lower total cost of ownership with pay-as-you-go pricing and zero fixed infrastructure costs. Self-hosting requires dedicated GPU rental overhead and consumes 0.25 to 0.5 of a full-time engineer's time for ongoing maintenance, making it economically unjustified until token volumes reach billions per month. This recommendation depends on maintaining standard token volumes below the break-even threshold and not having strict data residency mandates that explicitly forbid third-party API data transit.

## Findings
1. For organizations with token volumes below several billion per month, hosted APIs have a lower total cost of ownership than self-hosting open-weight models. [ev1] _(evidence: strong)_
2. Running one inference-class GPU around the clock costs roughly $1,100 to $2,900 per month before storage, networking, and monitoring, with a break-even point for self-hosting falling between 1 and 3 billion tokens per month. [ev2], [ev3], [ev4], [ev5] _(evidence: moderate)_
3. For a median early-stage startup processing 40 million tokens per month, monthly API spend remains under $500 for small models and between $800 and $2,500 when using frontier models. [ev7] _(evidence: moderate)_
4. Hosted APIs feature pay-as-you-go pricing that scales linearly with traffic and drops to near zero when usage is low, avoiding fixed monthly costs while searching for product-market fit. [ev8], [ev9] _(evidence: moderate)_
5. Keeping a self-hosted model reliable in production requires between 0.25 and 0.5 of a full-time engineer on an ongoing basis to handle patching, capacity, monitoring, and upgrades. [ev1], [ev13] _(evidence: strong)_
6. Dedicated GPU deployments achieve a faster median time-to-first-token of about 120 milliseconds compared to 250 to 600 milliseconds for shared APIs, though shared APIs can experience rate limits and higher 99th percentile latencies. [ev14], [ev15], [ev16], [ev17] _(evidence: moderate)_
7. While self-hosting keeps data within the organization's infrastructure, it does not remove security or regulatory compliance obligations, and institutions remain fully responsible for data governance and threat mitigation such as prompt injection. [ev6], [ev10], [ev11], [ev12] _(evidence: strong)_

## Recommendation
Use cloud LLM APIs for all inference needs while searching for product-market fit to preserve capital and avoid engineering overhead; revisit self-hosting only when token volumes consistently exceed 1 billion tokens per month.

**Impact:** medium

## Limitations
- The evidence does not cover scenarios where strict regulatory frameworks explicitly prohibit any data leaving internal infrastructure regardless of cost.
- Cost comparisons assume standard startup engineering salaries and specific hourly GPU rental ranges which may fluctuate.
